# Library for the assessment of goal fulfillment in uncertain scenarios using fuzzy theory

This repository contains the library and the experiments published in the following paper: Vincenzo Grassi, Raffaela Mirandola, and Diego Perez-Palacin. 2025. *Embracing Uncertainty: A Fuzzy Theoretical Model for Goal Fulfillment Assessment*. In 2025 IEEE/ACM 13th International Conference on Formal Methods in Software Engineering (FormaliSE). IEEE Press, 113–123. https://doi.org/10.1109/FormaliSE66629.2025.00018
